# Khảo sát dự án Claude

Mở tệp `index.html` bằng trình duyệt (bấm đúp vào tệp, không cần cài đặt hay máy chủ).
Trả lời 5 phần câu hỏi, rồi bấm **Tải tệp hướng dẫn** để nhận `huong-dan-du-an.md` và đưa vào dự án Claude.

Câu trả lời chỉ lưu trong trình duyệt trên thiết bị của bạn, không gửi đi đâu.
